About This System

This platform collects real-time weather data from multiple sources, processes it using AI/ML for verification and categorization, and provides comprehensive analytics through an interactive dashboard.

Key Features

  • Real-time data ingestion from social media and APIs
  • AI-powered fake news detection
  • Automatic event categorization
  • Duplicate removal and source verification
  • Interactive geospatial visualization
  • Admin panel for manual oversight
